# ZappeQc

Application de bureau Windows pour regarder gratuitement les chaînes québécoises en direct
(TVA, Noovo, Télé-Québec, ICI Télé, …) en intégrant les lecteurs web officiels des diffuseurs.

Pile : Tauri v2 + WebView2, React + Vite + TypeScript, pnpm.

```powershell
pnpm install
pnpm tauri dev
```

Voir `CLAUDE.md` pour les conventions et `docs/superpowers/specs/` pour les décisions d'architecture.
